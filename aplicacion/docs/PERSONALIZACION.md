# Hazlo tuyo · Control Emprende 4.0

La aplicación abre con azul profundo, superficies claras y acento verde. El nuevo Inicio separa ventas registradas, dinero cobrado, saldo por cobrar y resultado estimado; además muestra actividad reciente, próximas entregas, señales del asesor y meta mensual.

## Estilo

Abre **Hazlo tuyo** en la cabecera. En celular se representa con una paleta; también está en **Más → Ajustes → Personalizar mi espacio**.

| Paleta | Carácter |
| --- | --- |
| Impulso | Azul noche y verde vivo |
| Horizonte | Azul eléctrico y claridad |
| Órbita | Violeta creativo |
| Origen | Cobre cálido |
| Estudio | Rosa con carácter |
| Calma | Turquesa y equilibrio |

Puedes elegir un color propio. La aplicación adapta el color del texto sobre los botones y el acento usado en textos para conservar contraste. El modo Sistema sigue la preferencia clara u oscura de tu equipo. También puedes elegir espaciado compacto, texto grande y reducir animaciones.

## Identidad

Sube un logo PNG, JPG o WebP de hasta 2 MB. Se reduce para guardarlo localmente; no se admiten SVG ni direcciones externas. El nombre de tu espacio admite hasta 60 caracteres y tu frase hasta 110. El alias y el logo de este panel son visuales: no modifican el nombre comercial guardado ni los comprobantes.

## Mi inicio

Panorama organiza tarjetas en dos columnas cuando hay espacio; Enfoque las muestra en una columna. En teléfono ambas se adaptan a una columna. Usa las flechas para cambiar el orden de movimiento, entregas, decisiones y objetivo; desmarca las que no necesites. Los cuatro indicadores principales permanecen visibles. Si ocultas todas las tarjetas, aparece un acceso para recuperarlas.

Selecciona de uno a cuatro accesos rápidos entre venta, gasto, productos, clientes, cotizaciones, inventario, informes y asesor. Puedes ocultar toda esa fila. Los accesos no modifican los permisos de la cuenta.

## Guardar y recuperar

La vista previa es ilustrativa y no muestra importes reales. Pulsa **Aplicar mi estilo** para guardar; Cancelar o Escape permiten descartar un borrador. Restablecer estilo prepara los valores iniciales: debes aplicarlos para confirmar. Esta acción no borra los registros del negocio.

Las preferencias se guardan por **usuario y negocio en este navegador**. Cambiar de negocio conserva una configuración diferente. No se sincronizan con Supabase ni entre dispositivos y no forman parte del respaldo JSON de operaciones. Borrar los datos del navegador también elimina estas preferencias. Si el navegador no permite guardar o no tiene espacio, se muestra el error y el editor mantiene tu borrador.

## Qué incluye esta edición

Navegación y formularios con el nuevo sistema visual, inicio renovado, editor con vista previa, tema oscuro, diseño móvil y página comercial actualizada. Las operaciones, permisos y servicios entregados previamente conservan su funcionamiento. La edición 4.0 no necesita una nueva migración SQL y no activa servicios externos.
